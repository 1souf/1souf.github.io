What each check means
  • Audio broken — the file didn't load. Either it 404s or nothing came back within 10 seconds. A very slow connection can cause a false flag, so recheck before editing the sheet.
  • Audio missing — a song row with an empty Link(s) cell, so it can't be played at all.
  • Cover missing — the Cover & YT Link(s) cell on an album header is empty, or doesn't contain a plain http(s) URL. The site shows "NO COVER ON FILE" either way.
  • Cover broken — there's a cover URL but the image itself won't load. Some hosts block hotlinking, which looks identical from here.
  • Photo missing — an artist has no image URL in any album header's Feature(s) cell, so the sidebar falls back to a plain initial. This is checked per artist, not per album, because the site only ever uses the first one it finds.
  • Album empty — an album header with no song rows beneath it and nothing cross-listing into it through Original Era.
  • Download missing / YouTube missing — optional gaps, only counted when you tick the second box.
  • Tab problem — the tab couldn't be read at all, a required column header is missing from row 1 (Google hides any column whose header cell is blank), or a song row sits above the first album header where the site will never show it.
  • Files are only checked with a metadata request, so nothing is fully downloaded. The row number on each issue is the sheet row, if you need to go and fix it. A link that fails is retried once before it's reported — hosts like imgur throttle bursts, and a throttled image looks exactly like a deleted one.
